# IP 批量测试 App

一个安卓 App：批量测试 IP 的延迟、下载速度和归属地，帮你从一堆 IP 里快速挑出能用的、快的。

## 功能

- 批量输入：每行一个 IP，最多 200 条（超过只测前 200 条）
- 支持 IPv4 和 IPv6
- 并发测试：10 条同时测，速度比逐条快很多
- 自动测端口：依次试 443、8443、2053、2083、2087、2096、80、8080、8880，显示测通的端口
- 延迟测试：URL Test（HTTPS 请求耗时），失败的 IP 不显示，只在状态栏计入失败数
- 下载速度：对测通的端口测下载速度，测不到显示 `-`
- 归属地：只显示国家，如香港、美国、德国
- 实时状态：测试时状态栏实时显示正在测哪个 IP、已完成 / 成功 / 失败数
- 暂停：开始测试下方有暂停按钮，点一下停下剩下的，已测结果全部保留
- 导出结果：只导出测试成功的 IP，格式为 `IP:端口`（IPv6 为 `[IP]:端口`），可复制、可分享
- 一键清空：清空输入、结果和状态
- 结果排序：成功结果按延迟从低到高排序

## 使用方法

1. 打开 App，把 IP 列表粘贴进输入框（每行一个）。
2. 点「开始测试」，等状态栏显示完成。
3. 点「导出结果（仅成功 IP）」，复制或分享结果。
4. 想中途停下，点「暂停」，已测的照常显示和导出。

## 下载安装

- 推荐：打开本仓库的 Releases 页，下载最新版 APK，手机上点开安装（需允许“安装未知应用”）。
- 备用：打开本仓库的 Actions 页，找最新一次 Build APK，在 Artifacts 里下载 `app-debug-apk`，解压得到 APK 再安装。

## 自己编译

- 用 Android Studio 打开本仓库，点 Run 即可；或
- 把代码推到自己 fork 的仓库，GitHub Actions 会自动跑 `gradle assembleDebug` 编译出 APK。

## 隐私说明

- App 不注册、不登录、不收集你的个人信息。
- 归属地查询会把“被测的那个 IP”发给公开的 IP 归属地服务（如 ip-api）查询国家，这是测归属地本身必需的；你的输入列表不会上传到任何服务器。
